# 操作日志容量保护

## 异步扫描与取消（第十九轮，覆盖下方旧性能边界）

跨天查询使用统一文件入口的异步元数据读取、流式目录枚举和可取消文件读取，不再同步枚举/排序整天目录。10000上限计所有目录条目（含不匹配文件名），20MB计已读取字节，2000计匹配结果。单日目录内按文件系统枚举顺序扫描，返回的已读结果按时间排序；截断部分不保证是最早或最新记录。单条超过256KiB跳过并计入损坏/过大/不可读提示，保留原文件，避免大JSON解析独占事件循环。

点击“停止查询”、关闭面板、切换条件或网络断开会传递取消信号，服务端停止后续扫描；不会取消生成任务。目录迭代提前退出会关闭句柄，路由解除断开监听。10秒扫描软截止触发后返回已读结果、timedOut及未完成日期；前端15秒仍未收到响应则取消HTTP请求并提示读取失败。已经进入系统的元数据操作或目录打开协调队列不能强行中断，须返回后检查信号，不承诺硬10秒返回。

只读跨天查询不自记录操作日志，避免查询结束再次触发同步容量扫描。单日完整导出和其他业务的既有日志容量扫描仍保留，本轮不宣称全站磁盘操作都已异步。

回归使用10001条目及2001匹配记录的真实隔离文件，验证数量截断、时间排序及事件循环可响应；实际HTTP扫描中另一状态请求可返回，断开后观察到取消且后续读取停止。10秒超时采用10.05秒读延迟注入；目录打开时取消单独验证close调用。源码审查确认for-await退出释放句柄和协调锁，再次查询成功仅是附加行为证据。

## 按任务ID跨天排查（第十八轮，当前用法）

粘贴任务ID后默认查最近7个UTC日；任务卡片“查看流程日志”带入创建日至最近更新时间，超过7天则只带入最近7天。范围选择器和结果标题明确显示起止日期。需要更早记录时调整范围，无需逐日查询；记录时间按浏览器本地时区显示。单日完整导出仍使用独立日期选择，不受跨天范围影响。

跨天查询沿用GET /api/activity/export，参数startDay、endDay、taskId必须同时提供，不能与day混用；最多7个UTC日。全范围最多检查10000个文件、读取20MB、返回2000条匹配结果，升序扫描并排序展示，达到上限保留已读结果并列明未查完日期，建议缩小范围。这不是最近2000条保证。

missingDays表示无日志目录（不证明从未有任务）；failedDays表示目录无法读取；invalidFiles表示损坏/不可读或不安全文件已跳过；unscannedDays表示包含部分扫描的日期及后续未扫描日期。任一情况都标记incomplete，并明确不能据此判断未生成/未扣费。即使未报告缺口，也只是范围内当前可读日志，不是完整历史保证；并发新增、旧版未记录、拒写和崩溃缺口仍可能存在。被跳过内容不回显、不改写。

性能边界：同步文件扫描，无持久索引；10000文件限制不包含当日目录的完整枚举与排序。15秒客户端超时不会中断服务端同步扫描。20MB截断已实际回归，10000文件与2000结果上限本轮为代码审查，未进行对应规模实测。

## 按任务ID单日排查（第十七轮历史行为）

管理员打开生成任务，点击任务卡片“查看流程日志”，自动带入任务ID和最近更新时间所在的UTC日期；或在上方粘贴完整任务ID、选择日期并点击“查找任务日志”。记录按时间先后显示，阶段使用中文说明，时间显示为浏览器本地时区。跨天恢复需切换日期，未找到不能推断未提交，不要直接重新生成。

此入口复用GET /api/activity/export的可选taskId参数，只返回匹配的mediaTask/http白名单摘要，不带历史请求正文。权限仍为管理员或可信本地模式；不是成员的新权限。原当日完整JSON导出保持原有行为。

当前仍扫描所选UTC日的全部日志，整天总量超过20MB或任一被读取记录损坏会报错；不是跨日索引或完整历史搜索。页面错误与空结果分开，切日期、ID、项目、权限、关闭或卸载会清除旧结果并取消请求。日志被拒、旧版未记录、崩溃缺口均不会补造。

## 核心生成阶段定位（第十六轮）

沿用管理员按天导出的操作日志，按taskId关联HTTP请求及kind=mediaTask记录；无需新增日志页面。状态与计费状态分别记录，succeeded不代表账单已对账，elapsedMs为从原任务创建至事件的总时长（包含恢复等待），不是供应商推理耗时。

| stage | 含义 |
| --- | --- |
| statusChanged | 任务快照写入成功后的状态变化，涵盖排队、执行、保存、取消和终态 |
| statusSnapshot | 无历史时间线的旧任务保存摘要，不推定发生了状态转换 |
| submissionReused | 同ID同参数复用旧任务，未新调用生成 |
| providerTaskReceived | 首次取得或变更上游任务ID，同ID重复进度不另记 |
| recoveryStarted | 原任务进入续查流程，不是重新生成 |
| executionFailed / cancellationObserved | 捕获执行失败或取消，status为当时阶段，不含上游错误正文 |
| persistenceFailed | 任务快照保存失败，status为尝试保存的状态，不能视为已持久化成功 |

新增阶段日志仅含任务/项目/用户标识、模型标识、状态、计费状态、上游任务ID、文件数量和耗时；不含提示词、参考素材、路径、密钥或原始错误。既有HTTP/提示词日志内容规则未在本轮改写，不能据此宣称全站日志都不含提示词。日志容量或写入拒绝不改变生成结果，也不自动重试；查看既有容量拒绝告警。被拒日志不补写，任务快照与日志并非原子事务，进程崩溃可能产生缺口，不是强审计凭证。

适用对象：单进程 Toonflow 的 `data/activity` 操作日志。此能力不轮转、删除、压缩或覆盖历史日志，不是全机磁盘配额，也不替代供应商账单及防篡改审计。

## 策略

- 达到总字节、文件数或磁盘余量限制时，停止新增操作日志；现有文件原样保留。单条过大的事件被明确拒绝，不截断成一条看似完整的记录。
- 状态查询提供容量、限制、停止原因和本进程拒绝次数；管理员任务中心显示容量状态。查询失败显示状态未知，不能显示“正常”。
- `blocked=false` 不代表所有历史事件已留存：单条过大或剩余配额不足可能只拒绝一次事件；`lastRejectedReason`、拒绝次数及界面历史告警会明确说明，被拒事件不补写。
- HTTP完成后的日志失败不能撤回已经完成的业务操作。专门的日志记录接口仍返回失败；提示词辅助的前置记录失败会在调用模型前拒绝请求，后置记录失败则返回已生成建议及日志未保存警告，避免重复付费。
- 容量拒绝/存储故障的服务端告警限频，不打印事件正文、凭据或原始磁盘路径。拒绝次数为当前进程内计数，重启归零，不代表永久审计记录。

## 配置约定

通过服务进程环境变量配置，单位为字节或文件个数。仅接受正的安全整数；非法配置关闭新增日志并暴露原因，不静默使用无限容量。

| 环境变量 | 默认值 | 含义 |
| --- | --- | --- |
| `TOONFLOW_ACTIVITY_MAX_BYTES` | 268435456（256 MiB） | 日志文件内容累计字节上限 |
| `TOONFLOW_ACTIVITY_MAX_FILES` | 100000 | 日志文件总数上限 |
| `TOONFLOW_ACTIVITY_MAX_RECORD_BYTES` | 262144（256 KiB） | 单条序列化事件上限 |
| `TOONFLOW_ACTIVITY_MIN_FREE_BYTES` | 1073741824（1 GiB） | 写入前数据分区需保留的可用空间 |

这些默认值是本轮保守工程边界，不是经过容量压测的商业SLA。上限不是历史清理目标：已有日志超过上限时只停止新写，不删除已有日志。

## 检查与恢复

管理员可读取 `GET /api/activity/status`（同源工作台请求、原有登录权限）；成员不增加此权限。接口不返回日志内容、服务器路径或凭据。该状态查询不生成新的操作日志，避免监控自身消耗日志容量。

访问边界与原日志导出一致：启用登录保护时仅管理员；未启用时沿用已有可信本地模式。专门的日志记录请求被容量保护拒绝时返回503，不能据此重新执行已经完成的生成或提示词操作。

进程首次检查和每60秒检查扫描日志元数据；正常写入成功后累加计数，不在每条请求中全量扫描。磁盘查询失败或无法确认目录安全时停止写入。磁盘余量按本条内容写入后的余额检查；不承诺文件系统块/目录开销或其他进程写入的空间预留。当前只支持一个写入进程；外部文件变化到下一次扫描之间存在检测窗口，不能承诺多进程共享额度。

超限时应先检查状态与部署配置，评估日志价值及可用磁盘，再经授权调整容量或归档方案。本轮没有执行归档、移动、删除或生产配置变更。保留全部历史的前提下，通常需要增加容量或调整经评估的上限；不要通过重复提交生成请求尝试恢复日志。

所有运行结论以根目录 `ACCEPTANCE.md` 和 `ITERATION-LOG.md` 为准。临时目录故障注入通过不等于真实磁盘耗尽或生产部署已验收。

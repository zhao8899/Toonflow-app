## P0 文件上下文与任务归属（2026-10-24）

- [x] 项目上下文中间件复用到 `/api/workspaces/files`；GET/HEAD 和原始二进制写入取 query 目录，其他文件操作取 body 目录，保留现有入参及文件冲突检查。
- [x] `useWorkspaceFiles()` 随当前项目同步读取目录和 ID；`useWorkspaceFiles(directory, projectId)` 支持显式绑定，两参数可为字符串/ref/getter。显式目录未传 ID 时保持旧行为，不借用当前项目；跨 await、防抖与保存队列须同时固定目录和 ID 字符串。
- [x] 文件所有方法传递项目头；文本 Range、二进制 Content-Type、快照修订号保留。Blob 缓存键增加项目 ID，任务结果下载固定目录与 ID。
- [x] 媒体任务创建公共函数从服务端登记表按规范目录匹配项目，保存可选 `projectId`，覆盖后台提交及同步节点/Agent 生成的公共链路。未登记任务不伪造归属，旧任务不回填，幂等重试保持原归属。
- [x] 临时目录实际 HTTP：原始写入/读取/快照/删除 200，快照文本正确，旧修订号 409，跨项目写入 403。第一次沿用临时记录时目录已不存在，接口正确返回 404；通过原有 API 重建临时工作目录后重跑通过。
- [x] 实际提交未配置模型任务，返回正确项目 ID，查询落盘记录保留 ID，重复提交 ID 相同；没有调用收费供应商。
- [x] 独立只读复核无阻断，确认文件头、路径快照及新增依赖无循环初始化问题。服务端类型检查通过；前端封装改动后的两端类型检查/构建均通过，后续调用方迁移须再执行集成检查。
- 边界：项目 ID 是创建时归属快照，不是成员授权判据；目录需完全匹配登记路径，子目录不自动继承归属。无项目头的旧请求仍兼容，尚不能开放不可信用户。文档/画布调用方迁移及浏览器交互验收继续推进。

显式项目快照用法：在操作开始时读取项目对象，将其 `directory` 与 `serverProjectId` 一并传给 `useWorkspaceFiles`，之后复用该实例；不要在 await 后重新读取当前项目来补 ID。

- 未新增测试文件、未改真实数据、未提交或发布。下一阶段需将项目 ID 及成员能力域贯穿业务访问，特权执行隔离完成前仍不开放普通用户工作台。

### 启用方式与边界

| 环境变量 | 说明 |
| --- | --- |
| `TOONFLOW_AUTH_REQUIRED` | 设置为 `true` 启用；未设置或 `false` 保持原单机访问方式。非法值启动失败，不静默降级。 |
| `TOONFLOW_ADMIN_USERNAME` | 首次初始化时必填，3～20 字符；不能与已有普通账号重名。 |
| `TOONFLOW_ADMIN_PASSWORD` | 首次初始化时必填，12～1024 字符；通过部署环境注入独立强密码，不提交到仓库。 |

配置后按原有命令启动独立 server，通过浏览器访问。本模式暂不支持原生桌面或移动宿主，误用于原生宿主时明确拒绝启动，避免登录页与启动屏互相等待。管理员创建成功后可移除两个初始化凭据环境变量；已有管理员时不会重置密码或更改角色。没有管理员且缺少有效初始化凭据时拒绝启动。

远程访问需要 HTTPS，反向代理需保留外部 Host 和浏览器 Origin/Referer。不信任转发 IP，反向代理后的用户共享登录限额。回环地址允许 HTTP 供本机使用。浏览器请求和业务 API 必须同源部署。

这是可信管理员使用的共享工作台，不是多租户产品：管理员可以访问全局设置、插件、Agent 和授权工作区。普通账号不允许进入，尚无账号管理与密码恢复页面。会话撤销对后续请求生效，已经启动的后台生成任务不因此取消，已有长连接不承诺立即断开。

## 关键边界

- 本轮面向现有单实例/可信工作区部署，不宣称完成多租户隔离。任务查询权限继承现有工作区权限。
- 服务进程重启后，未结束任务标记为中断；上游没有统一查询协议，不自动重发、不声称能续跑上游任务。
- 生成请求取消不代表上游取消或退款。费用仍由所选供应商账户结算；不引入第二套虚假余额。
- 同一 ID 的重试只返回原任务；用户主动再次生成会创建新任务，可能再次收费。
- 单进程最多 8 个媒体任务同时执行，任务单文件原子保存；历史列表按项目扫描，规模扩大后再迁移索引或数据库。
- 结果保存成功后保留文件；任务记录写入异常须暴露，不通过重新调用供应商修复。

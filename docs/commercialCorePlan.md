结论：具备进入受控团队试点的技术基础，尚未完成正式商用验收；不应作为多客户自助充值、统一余额计费的 SaaS 直接开放。下方日期章节是历史实施记录，不等于全部当前状态；例如成员生成、刷新恢复、每日次数限额已在后续完成实现。

### 先验证交付模式

- 优先验证单客户独立实例/托管团队工作台：实例独立数据目录、供应商账户和备份，管理员明确知晓其权限范围；先提供部署、培训、运维与创作流程服务。客户自备供应商账户，或实际用量人工核对后结算，均需明确合同边界。
- 若统一代付模型费用，必须先建立逐任务成本核对与异常处理流程；次数上限不是金额上限。未确认成本与质量前，不承诺无限生成或固定利润。
- 多客户共用同一实例属于后续独立工程：项目成员隔离不能等同于租户隔离，管理员、配置、插件、Agent、MCP、文件和供应商账户都需纳入隔离边界。

## 成员额度可见性（2026-10-26）

- 新增 `GET /api/ai/media/tasks/quota`，返回本项目 `limit/used/remaining/resetAt/enabled`，复用实际提交的同步计数方法，保持原幂等与并发检查顺序。接口复用项目成员与目录鉴权，不包含他人任务明细。
- 生成弹窗显示今日已用、上限、剩余及北京时间重置时刻；支持刷新。额度未知、停用或耗尽时不允许新提交；新提交前再读取额度，服务端仍最终校验。429 后刷新额度但不自动重试；原请求幂等重试与只读确认不依赖剩余额度。
- 切换项目时清除旧额度，忽略过期响应；待确认请求显示独立查询入口，不展示可能属于另一个项目的额度刷新按钮。
- 隔离实例 HTTP 验证：限额 2、已有 1 次时返回已用 1/剩余 1；停用状态如实返回 false；缺项目头 403、匿名 401、非成员 404。以指定时间调用实际计数方法验证北京时间午夜前后重置时间正确（不是等待真实跨日验收）。临时授权和限额已恢复，未调用付费生成。
- server/web 类型检查与构建通过；浏览器交互、高并发和真实跨日验收仍待完成。次数额度不代表金额预算。

### 启用方式与边界

| 环境变量 | 说明 |
| --- | --- |
| `TOONFLOW_AUTH_REQUIRED` | 设置为 `true` 启用；未设置或 `false` 保持原单机访问方式。非法值启动失败，不静默降级。 |
| `TOONFLOW_ADMIN_USERNAME` | 首次初始化时必填，3～20 字符；不能与已有普通账号重名。 |
| `TOONFLOW_ADMIN_PASSWORD` | 首次初始化时必填，12～1024 字符；通过部署环境注入独立强密码，不提交到仓库。 |

配置后按原有命令启动独立 server，通过浏览器访问。本模式暂不支持原生桌面或移动宿主，误用于原生宿主时明确拒绝启动，避免登录页与启动屏互相等待。管理员创建成功后可移除两个初始化凭据环境变量；已有管理员时不会重置密码或更改角色。没有管理员且缺少有效初始化凭据时拒绝启动。

远程访问需要 HTTPS，反向代理需保留外部 Host 和浏览器 Origin/Referer。不信任转发 IP，反向代理后的用户共享登录限额。回环地址允许 HTTP 供本机使用。浏览器请求和业务 API 必须同源部署。

这是可信管理员使用的共享工作台，不是多租户产品：管理员可以访问全局设置、插件、Agent 和授权工作区。普通账号不允许进入，尚无账号管理与密码恢复页面。会话撤销对后续请求生效，已经启动的后台生成任务不因此取消，已有长连接不承诺立即断开。

决策：保留原单机部署默认值，需明确启用本模式；先关闭与新会话不兼容的外部通道，不假装它们已完成租户授权。不得把未启用模式当作已受登录保护。

# 任务成本台账第一版

> 本文保留阶段性方案/演练记录。当前结论见[验收记录](../ACCEPTANCE.md)；文中旧轮次详见[历史验收](archive/round46/acceptanceHistory.md)。操作前核对目标环境与授权。

日期：2026-10-29。

## 已实现

- 任务中心终态任务提供成本核对，记录已核对或待处理状态、金额、CNY/USD币种、依据、说明、时间和操作者。金额使用十进制字符串，最多12位整数和6位小数，不用浮点数记账。
- 无记录表示未知；待处理可使用null金额，已核对必须提供金额，0仅代表人工明确记录为0。拒绝负数、指数格式与超精度金额。
- 费用与生成状态独立，不改变供应商billingState，不执行扣费退款，不把失败或取消推断为免费。原任务续查不自动修改人工账单记录；实际费用变化需重新核对。
- 登录保护模式仅管理员能读写或导出成本；可信本地模式允许操作，操作者明确为未认证。身份从服务端读取，不接受客户端伪造。
- 成本与历史保存在任务原子快照，revision避免旧内容覆盖新记录，保留最近100次历史。常规任务返回不暴露成本或核对历史。
- 项目全部任务可导出JSON，包含本地/上游ID、模型、发起人、生成状态及当前成本；未知为null，不受界面筛选影响。上限10000任务，超过拒绝；不做跨币种合计。
- 关闭界面、切换项目或权限状态时取消请求，防止过期响应覆盖新表单。保存失败保留输入；发生版本冲突时明确要求重新读取。
